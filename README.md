# TikTok-Auto-Continued-Spark

抖音自动续火助手（浏览器扩展版）—— 基于原油猴脚本改写的 Chrome/Edge 扩展，用于电脑网页版抖音消息页自动发送续火消息。

> 该扩展仅供学习交流使用，请勿用于任何商业用途。

## 特性

- **自动续火**：按设定时间每日自动向目标用户发送续火消息，支持火花天数自动累计
- **多用户支持**：目标用户列表 + 顺序/单一模式，自动查找目标用户会话并发送
- **消息组合**：支持"续火文案 + 一言 + 专属一言 + 自定义文本 + 火花天数"多维组合
- **丰富设置项**：6 个设置 Tab（基本 / 消息 / API / 专属一言 / 用户 / 高级）
- **用户选择面板**：搜索、查看在线状态、切换目标用户、发送状态角标（群聊 / 无火花 / 已发送 / 跳过 / 失败）
- **失败重试**：自动重试机制 + 定时重置重试计数
- **后台代理**：跨域 API 请求经 service worker 代理，支持系统通知（发送成功 / 失败）
- **薄荷清新 UI**：全面板薄荷绿主题，可拖拽悬浮球随时重新打开面板

## 与原油猴脚本的差异

本扩展在保留核心续火功能的前提下，移除了以下内容：

- **自定义后端回调**（Searxng API 地址 / 密钥 / 自定义指令 / 系统提示词 / 温度等 AI 相关配置）
- **连续对话模式**
- **导出用户会话**

⚠️ 数据不迁移：本扩展与油猴版使用相互独立的 localStorage 存储，两者数据互不影响。

## 安装

1. 克隆或下载本项目
2. 打开 Chrome 或 Edge，进入扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
3. 打开右上角 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择本项目的 `extension/` 目录
5. 打开抖音网页版消息页：`https://www.douyin.com/chat`（或创作中心私信页 `https://creator.douyin.com/creator-micro/data/following/chat`）

> 建议只安装本扩展，不要与油猴版脚本同时使用，否则会重复发送消息。

## 使用说明

### 主面板

- **🚀 立即发送**：立即执行一次发送流程
- **⏸️ 暂停 / ▶️ 继续**：暂停或恢复自动发送
- **🔄 重置记录**：清除今日已发送用户记录
- **⚙️ 设置面板**：打开设置
- **📋 历史日志**：查看操作日志
- **📅 火花天数**：手动修改当前火花天数
- **🗑️ 清空天数**：清空火花天数记录
- **👥 用户选择**：打开目标用户选择面板
- **🔄 重置重试**：重置失败重试计数并立即发送
- **🗑️ 清空数据 / 🔧 重置配置**：恢复出厂设置

面板右上角关闭后，会显示一个可**拖拽**的悬浮球（🔥），拖动不会误触点击；轻点悬浮球可重新打开面板。

### 设置面板

| Tab | 说明 |
| --- | --- |
| 📅 基本设置 | 每日发送时间 / 随机时间段、定时重置间隔、初始延迟、重试设置 |
| 💬 消息设置 | 基础续火文案、自定义消息模板、文案格式 |
| 🔗 API 设置 | 一言 API 开关与地址、TXTAPI 开关与模式、超时时间 |
| 🌟 专属一言 | 按星期（周一~周日）配置专属文案、随机开关 |
| 👥 用户设置 | 启用目标用户查找、目标用户名列表、多用户模式（顺序 / 单一）、查找超时 |
| ⚡ 高级设置 | Chat 页面行分隔符、输入框检测间隔、页面加载等待、点击方式（direct/脚本）、滚动查找间隔 |

### 用户选择面板

- 实时搜索、查看用户在线状态
- 点击列表项可切换当前目标用户
- 每个用户显示发送状态角标

## 常见问题

**Q：获取会话列表提示 `v1.hitokoto.cn` 不可达？**
A：一言 API 请求有 15 秒超时。网络不可达时请关闭一言/专属一言开关，或稍后重试。不影响核心发送功能。

**Q：用户都显示"群聊"徽标？**
A：抖音网页版 `/chat` 页面部分场景不返回用户详情接口，此时不会误标为群聊。若仍显示异常，请刷新页面重新进入。

**Q：需要保持页面一直开着吗？**
A：是的，扩展在消息页内执行发送逻辑，需要保持聊天页处于打开状态。

**Q：数据存在哪里？**
A：全部保存在浏览器本地（localStorage），清除浏览器数据会一并清除。

**Q：安装时提示需要访问所有网站的权限？**
A：`<all_urls>` 是后台 service worker 代理跨域 API 请求（一言等）所需，扩展不会收集任何数据。

**Q：发送失败怎么处理？**
A：默认自动重试，可在"基本设置"调整最大重试次数；重试达上限后按设定间隔自动重置（设置为 0 禁用）。"🔄 重置重试"可手动立即重试。

## 技术架构

```
┌────────────────────────────────────────────────┐
│  manifest v3                                   │
│                                                │
│  interceptor.js (MAIN world, document_start)   │
│    拦截页面 fetch/XHR → postMessage 桥接       │
│  content.js (ISOLATED world, document_start)   │
│    GM shim + 原脚本主体 + 薄荷清新 UI 面板     │
│  background.js (service worker)                │
│    GM_xmlhttpRequest 代理 + 系统通知 + storage  │
└────────────────────────────────────────────────┘
```

- `extension/interceptor.js`：在页面主世界拦截请求，经 `postMessage` 桥接给 content script
- `extension/content.js`：全部核心逻辑与界面（约 4400 行，含 GM_* shim）
- `extension/background.js`：跨域请求代理、系统通知、storage 中转
- `extension/icons/`：薄荷绿火焰图标（16/48/128）
